# The Game of Life · Colour Edition

A colour reading edition of *The Game of Life and How to Play It* by Florence Scovel Shinn (1925, public domain), with scriptures in gold, key verses (KJV), affirmations, key truths, coach's notes and weekly practices.

Features: verse and affirmation of the day, reading streak, chapter journal, read-aloud, quote-card maker, highlights, search, Stop here bookmark, installable app with offline reading.

Everything a reader saves (bookmark, journal, highlights, streak) stays in their own browser. Static site, no build step: Vercel serves the files as they are.
